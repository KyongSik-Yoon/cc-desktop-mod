Follows Claude Code 2.1.305: pasted-image thumbnails and round bubble corners now draw in iTerm2 3.5 and later under fullscreen rendering.

- iTerm2 3.5+ with fullscreen rendering (`/tui fullscreen`, the default outside tmux) draws the multi-line bubble's corners as pictures and shows `[Image #N]` as a thumbnail above your prompt bubble, as kitty and Ghostty already did
- On the main screen, inside tmux, with `CLAUDE_CODE_ALT_SCREEN_FULL_REPAINT`, or on older iTerm2, the bubble keeps its glyph corners as before
- In iTerm2 a pasted image over 2 MiB stays as `[Image #N]` text (Claude Code sends iTerm2 picture bytes, not file names)

## Install

```
/plugin install desk-look --marketplace KyongSik-Yoon/cc-desktop-mod
```

Already installed: `/desk-update` (or `claude plugin update desk-look`), then `/reload-plugins`.
